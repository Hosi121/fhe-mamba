# Archived results

[`pre-compat-retirement/`](pre-compat-retirement/) contains the previously
tracked `runs/` files from the retired Stage 0/1/2 implementation. File contents
are unchanged. Embedded `runs/...` paths describe the original environment;
for a tracked file, replace that prefix with
`results/archive/pre-compat-retirement/` to locate it here.

The [historical ledger](../../docs/archive/artifact-ledger.md) also names outputs
that were never committed. A recorded path in that ledger does not mean the
artifact is available. The retired implementation is available at the pinned
[archive commit](../../docs/archive/legacy-implementation.md).

These are provenance records, not current commands or acceptance gates.
Current results are indexed in [`../README.md`](../README.md).
